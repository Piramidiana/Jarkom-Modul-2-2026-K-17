# Skrip Tedd

Ketujuh skrip di direktori ini berasal dari keluaran console Tedd. Jalankan tahap DNS hanya pada node Tedd dan setelah Master Prab siap; `dns-tedd-3.sh` menghentikan serta memulai ulang `named`, dan meminta transfer ulang seluruh zona. Dokumen ini mengarsipkan skrip, bukan perintah untuk menjalankannya ulang.
